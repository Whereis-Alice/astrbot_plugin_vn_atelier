# 配置指南

[返回首页](../README.md) · [指令说明](usage.md) · [常见问题](faq.md) · [LLM 工具](llm-tools.md)

在 AstrBot WebUI → 插件管理 → Gal工房 → 配置中修改。以下列出常用设置；其余选项以面板中的说明为准。修改后保存，必要时重载本插件，无需为此重启整个 AstrBot。

通常不需要填写任何令牌即可查询公开资料。先确认服务器能访问对应数据源，再按需设置代理、图片清晰度和推送。

## Bangumi 数据（优先来源）

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 启用 Bangumi | 开 | 作品查询与默认排行优先使用 Bangumi；关闭后使用 VNDB |
| 补充已有卡片与每日推送 | 开 | 为 VNDB / TouchGal 作品关联 Bangumi；关闭不影响直接 BGM 查询 |
| Bangumi Access Token（可选） | 空 | 公开数据无需填写；受限条目可在 [Bangumi 官方页面](https://next.bgm.tv/demo/access-token) 生成。还需账号权限及 NSFW 开关，不保证所有条目可读 |
| Bangumi 单次超时（秒） | 12 | 独立于通用网络超时；跨站匹配总等待最多约此值 + 4 秒 |
| Bangumi 数据缓存（小时） | 6 | 分数不是实时数据；重载清空。未匹配缓存最多 30 分钟，临时失败更早重试 |
| Bangumi 搜索结果上限 | 8 | 1–12 条 |
| BGM评分榜最低评价人数 | 100 | 只影响默认 Bangumi 榜单和 BGM排行，不影响普通搜索 |

Bangumi 使用官方 `api.bgm.tv` 接口，不需要浏览器、FlareSolverr 或 Cloudflare Worker。它遵循本插件的 HTTP/HTTPS 代理设置；若你的出口无法访问该接口，需自行配置可用网络。访问令牌仅用于该接口，不发送给图片服务器或其他来源。

## 通用设置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 单次请求最大尝试次数 | 5 | 图片或数据经常下载失败时可以调高，代价是响应变慢 |
| 单次请求超时（秒） | 30 | 网络慢或走代理时建议 45 以上 |
| 会话等待超时（秒） | 60 | 推荐、出处等指令等待你下一条消息的时长 |
| 合并转发单条包含的消息数 | 10 | 单条转发内容太多容易被平台拒收，0 表示不拆分 |
| 下载资源最多展示条数 | 0 | 0 表示全部列出 |
| 渲染失败时退回纯文本 | 开 | 建议保持开启 |

## 外观与渲染

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 配色主题 | 星夜 | 星夜（深蓝夜空）/ 樱色（淡粉暖调）/ 青瓷（素雅冷绿）/ 墨影（高对比黑金） |
| 字体来源 | 在线字体 | 在线字体观感最好但要能访问 CDN；也可以改用系统字体或交给浏览器默认值 |
| 在线字体 CSS 地址 | 霞鹜文楷 jsDelivr | CDN 不通时可换国内镜像 |
| 字体名称 | LXGW WenKai | 用系统字体时改成本机确实装了的中文字体 |
| 清晰度 | 高清（1.3x） | 给渲染页面装一块高分屏。觉得字发虚就调到超清，详见[图片清晰度说明](faq.md#图片不够清晰怎么调) |
| 图片格式 | JPEG | PNG 无损但通常体积更大，一般不需要换 |
| 图片质量 | 95 | JPEG 压缩质量，调低可以让发图更快；选 PNG 时该项不生效 |
| 显示页脚 | 开 | 图片底部的数据来源与生成时间 |

## 网络与内容分级

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 允许 R18 内容 | 关 | 按数据源标记过滤成人条目和图片，第三方标记可能不完整 |
| 代理地址 | 空 | 只作用于本插件，例如 `http://127.0.0.1:7897`；Bangumi 仅支持 HTTP/HTTPS，其他通用请求可使用 SOCKS5 |
| TouchGal 站点地址 | `https://www.touchgal.ink/` | 可填站点或自己部署的 Worker 完整地址，见[验证排障](faq.md#站点开启浏览器验证怎么办) |
| TouchGal 登录 Token | 空 | 留空只能看到公开资源，取法见 [TouchGal 排障](faq.md#下载查不到资源或出现-403) |
| Cloudflare cf_clearance | 空 | TouchGal 的临时凭证，只填值本身；迁移、过期或环境变化可能失效，与 Bangumi 无关 |
| 浏览器 User-Agent | 空 | 只在填了 cf_clearance 时需要，必须来自同一个浏览器；留空则按下面的指纹档位自动推一个 |
| 浏览器验证求解服务 | 空 | 可选 FlareSolverr 服务，不保证通过所有站点验证 |
| TLS 浏览器指纹 | chrome136 | curl_cffi 伪装用的浏览器标识，绕不过需要执行 JavaScript 的验证页 |

## 每日推送

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 推送时间 | 07:00 | 24 小时制 HH:MM，格式错误会退回默认值并写日志 |
| 选取作品的口味 | 评分优先（排除冷门） | 也可以选纯评分优先或热度优先 |
| 生日角色性别筛选 | 不筛选 | 可只推女性或只推男性角色 |
| 启用群聊自助订阅 | 开 | 开启后 AstrBot 管理员可以在群里直接订阅 |
| 推送白名单 | 空 | 手动指定会话，每行一条，格式「平台id-群聊id」，如 aiocqhttp-123456789 |

## 缓存与限流

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 磁盘缓存上限（MB） | 256 | 超出后按最久未使用顺序删除，0 表示不限 |
| 缓存有效期（天） | 14 | 0 表示永不过期 |
| 内存缓存条数 | 64 | 命中时连磁盘都不用读，0 表示关闭 |
| 同一用户指令冷却（秒） | 3 | 0 表示不限制 |
| 开放给大模型调用 | 关 | 开启后注册四个查询工具，保存后重载；详见 [LLM 工具指南](llm-tools.md) |

## 各指令的细节

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 角色卡附加信息 | 血型 / 身高体重 / 性别（不剧透） | 还可勾选三围、罩杯、含剧透的性别 |
| 每个厂商展示的作品数 | 9 | 按评分降序取前 N 部，0 表示全部 |
| 榜单展示条数 | 12 | — |
| 最低投票数门槛 | 100 | VNDB 榜单专用；Bangumi 使用上面的独立门槛 |
| 推荐预取数量 | 5 | 提前渲染几部，减少「换一个」的等待时间，但会增加预取请求 |
| 每个检测框的候选数 | 3 | 识图时每张脸给出几个候选角色 |
| 作品质量门槛（简讯设置） | 75 | 只统计贝叶斯评分不低于此值的作品 |
| 回溯起始年份（简讯设置） | 1990 | 想翻更早的老作品可以往前调 |

## 手动填写 LLM 开关

使用配置文件时，对应字段如下。这只是片段，请合并到已有配置，不要覆盖整份配置。

```json
{
  "limitSetting": {
    "enableLlmTools": true
  }
}
```

工具仅在插件初始化时注册；保存后重载 Gal工房。首次启用时日志应出现「已注册 4 个 LLM 工具」。

## 环境要求

- AstrBot ≥ 4.16、Python ≥ 3.10；运行依赖由 AstrBot 按 `requirements.txt` 安装。
- 图片卡片使用 AstrBot 的图片渲染服务；仅查 Bangumi 文字资料不需要浏览器。
- Bangumi 使用 HTTP/HTTPS 代理；不要给它直接填写 SOCKS5 地址。TouchGal 的可选浏览器服务只用于该来源，不参与 Bangumi 查询。
