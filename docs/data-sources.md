# 数据来源与评分说明

[返回首页](../README.md) · [指令说明](usage.md) · [配置指南](configuration.md)

## 从哪里查资料

| 来源 | 用途 |
| --- | --- |
| [Bangumi](https://bgm.tv/) | 优先的游戏名称、评分、评价人数、排名、简介、平台与制作数据 |
| [VNDB](https://vndb.org/) | 视觉小说作品、角色、会社、评分、发售日期与标签 |
| [TouchGal](https://www.touchgal.ink/) | 部分中文简介、游戏截图与资源链接 |
| [AnimeTrace](https://www.animetrace.com/) | 根据图片识别角色与出处 |

数据的完整性、译名和更新速度取决于原站。请遵守各站使用条款，不要高频抓取，也不要将插件回复视为官方发行或购买建议。

## 查询来源如何选择

- `工房 作品` 优先搜索 Bangumi 游戏，无结果或查询失败时回退 VNDB；关闭「启用 Bangumi」时使用 VNDB。
- `工房 BGM` 只查 Bangumi；`工房 ID` 只接受 VNDB ID，例如 `v17`、`c123`、`p45`。两种 ID 不通用。
- 角色、会社及每日日期选题来自 VNDB：纪念日查往年首发，生日按月日查询，新作按今日首次发售日期查询；不是全站热门榜或已确认上架通知。规则见[每日推送说明](daily-push.md)。
- VNDB / TouchGal 作品卡片可以尝试补充 Bangumi 数据；补充失败不阻断原有卡片。
- 资源查询依赖 TouchGal；该站不可用时不能保证得到资源链接。Bangumi 查询不经过 TouchGal 或其 Worker。

## 两站评分不混算

- **Bangumi：10 分制。** 同时展示可取得的评价人数与游戏排名。
- **VNDB：100 分制。** 作品卡和评分榜主要使用贝叶斯评分；文字资料还可能列出原站平均分，并分别标注。
- 两站投票人群、算法和条目划分不同，不能简单换算或合并成一个「综合分」。
- 暂无有效评分显示「暂无」，不是 0 分；没有排名时不编造排名。

Bangumi 数据默认缓存 6 小时，分数不一定实时变化。缓存设置见[配置指南](configuration.md)。

## 只使用 Bangumi 游戏条目

同名动画不会被拿来补游戏评分。Bangumi 游戏分类也包含非 Galgame 作品，因此无标签的检索或榜单可能出现其他类型游戏。

想收窄榜单范围，可以使用 `工房 排行 2024 galgame`；结果仍取决于原站标签。

## 每日推送为什么不总有双评分

跨站关联采用保守规则：优先可用的条目外链；其次检查精确标题或别名，并在两边都有发售日期时核对年份。
遇到冲突、续作名不同或多个精确候选时不猜测，也不会拿不可靠的搜索摘要补上评分。

因此，卡片可能只展示 VNDB 评分，并标注「未找到可靠关联条目」「候选有歧义」或「暂不可用」。这不一定是卡片故障，也不表示 Bangumi 一定没有收录该作。
译名、移植版本和条目划分差异都可能导致无法可靠匹配。

生日角色补充仅在已可靠关联的游戏内核对精确姓名／别名，并拒绝已知生日冲突或同名歧义；不可靠时保留 VNDB 原资料。Bangumi 有角色生日数据，但公开角色搜索没有月日筛选条件，所以生日名单继续由 VNDB 提供。

## 评分榜与官方排名的区别

- `工房 排行` 默认按 Bangumi API 评分排序，并筛选最低评价人数。卡片里的「游戏 #排名」则是原站提供的排名；二者含义不同。
- `工房 BGM排行` 明确使用 Bangumi，接口失败时不会偷偷换成 VNDB 榜单。
- `工房 VNDB排行` 明确使用 VNDB 贝叶斯评分和对应最低票数门槛。
- Bangumi 与 VNDB 的最低评价人数设置彼此独立。过滤年份、标签或最低票数后得到的是筛选列表，不是对原站榜单的完整复制。

## 令牌与内容权限

公开 Bangumi 资料通常无需令牌。受限条目需要结合原站账号权限、「允许 R18 内容」设置和访问令牌判断，填写令牌不代表一定可见。
Bangumi 令牌仅发送给其 API，不发送给图片服务器或其他数据源。

TouchGal 登录 Token 与 `cf_clearance` 是不同凭证，均不能用于 Bangumi。验证失败时见[常见问题](faq.md)。
