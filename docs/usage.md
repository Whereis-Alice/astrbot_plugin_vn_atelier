# 指令说明

[返回首页](../README.md) · [配置指南](configuration.md) · [常见问题](faq.md) · [LLM 工具](llm-tools.md)

主指令是 **工房**，也可以写 `vna`、`VNA`、`gal工房`。下表中 `<>` 是必填参数，`[]` 是可选参数。

## 检索

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `工房 作品 <关键词>` | 游戏 / vn | 优先 Bangumi 游戏搜索；无结果或不可用时回退 VNDB |
| `工房 BGM <关键词 / ID / 链接>` | bgm / Bangumi / bangumi / 评分 | 查询 Bangumi 游戏；唯一结果或精确 ID 输出完整评分档案，多结果输出列表 |
| `工房 角色 <关键词>` | 人物 / character | 按名称检索角色档案 |
| `工房 厂商 <关键词>` | 作者 / producer | 检索会社或社团，并列出它的代表作 |
| `工房 ID <VNDB ID>` | id | 用 `v17` / `c123` / `p45` 精确查询，作品尝试补充中文简介 |
| `工房 排行 [年份] [标签]` | 榜单 / ranking | 默认 Bangumi 游戏评分榜；关闭 Bangumi 后使用 VNDB 榜单 |
| `工房 BGM排行 [年份] [标签]` | bgm排行 / Bangumi排行 / bangumi排行 | 明确使用 Bangumi，按评分及最低评价人数筛选 |
| `工房 VNDB排行 [年份] [标签]` | vndb排行 | 明确使用 VNDB 贝叶斯评分及最低票数筛选 |

## 发现

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `工房 随机` | random / 抽一部 | 随机抽一部作品，按数据源可用情况附简介与截图 |
| `工房 推荐 <标签...>` | 标签 / recommend | 按标签连续推荐，回「换一个」继续，回「结束」收工 |
| `工房 简讯 [月-日]` | event / 今日 | 当天有哪些作品发售纪念日、哪些角色生日 |
| `工房 出处 [图片链接]` | 识别 / find | 以图识别角色与出处 |
| `工房 下载 <ID 或关键词>` | 资源 / download | 查询 TouchGal 上的资源链接 |

## 个人

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `工房 收藏 <VNDB ID>` | mark | 加入个人收藏夹，作品、角色、厂商均可，单人上限 100 项 |
| `工房 取消收藏 <VNDB ID>` | unmark | 从收藏夹移除 |
| `工房 清单 [清空]` | 收藏夹 / collection | 查看收藏夹，带「清空」则全部清除 |
| `工房 帮助` | help / 菜单 | 展示完整指令表 |

## 管理员

需要 AstrBot 的管理员权限。

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `工房 主题 [名称]` | theme | 切换配色并写回配置；不带参数则列出可选主题 |
| `工房 缓存 [清理]` | cache | 查看缓存占用，带「清理」则立即清空 |
| `工房 推送 开启/关闭` | subscribe | 订阅或退订本会话的每日简讯 |

## 用起来大概是这样

```text
工房 作品 CLANNAD
工房 BGM 13                  用 Bangumi 游戏 ID 精确查详情
工房 BGM https://bgm.tv/subject/13
工房 厂商 Key
工房 ID v17
工房 排行 2024 galgame        Bangumi 游戏评分榜；也可以只写年份或标签
工房 VNDB排行 2016 百合       明确查询 VNDB 榜单
工房 推荐 治愈 校园          之后回「换一个」看下一部，回「结束」停下
工房 简讯 06-24              指定日期，省略则查今天
工房 出处                    把图和指令一起发出，或者先发指令再补一张图
工房 收藏 v17
工房 主题 青瓷
```

## 使用提示

- 如果 AstrBot 设置了指令前缀，请按实际配置在指令前加上前缀，例如 `/工房 帮助`。
- Bangumi ID 是数字，VNDB ID 带 `v`、`c` 或 `p` 前缀，不能混用。收藏使用 VNDB ID。
- 默认排行按 Bangumi 评分和最低评价人数筛选，不等同于原站官方排名。两站评分含义见[数据来源与评分说明](data-sources.md)。
- 图片无法生成时，默认会发送文字结果。想让聊天模型查资料，请按 [LLM 工具指南](llm-tools.md)单独开启。
